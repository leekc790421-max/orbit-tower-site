BUILDER · SETUP GUIDE

安裝步驟指南

Windows 10/11 · macOS 13+

🪟 Windows 10 / 11

  1. 下載 builder-t{1,2,3}-v5.2.0.zip 至「下載」資料夾
  2. 右鍵 ZIP →「解壓縮全部」→ 選擇目標資料夾(如 C:\xingdeng-builder)
  3. 進入解壓縮資料夾,找到 CHECKSUM.sha256
  4. 以 PowerShell 執行 Get-FileHash builder-t*.zip -Algorithm SHA256 對照
  5. 雙擊 setup.exe 啟動設定精靈
  6. 依精靈指示填入:網站名、LOGO 路徑、電話、LINE ID、地址、主色碼
  7. 點擊「完成」,系統自動產出網站檔案至 output/ 子資料夾
  8. 進入 output/,依「部署說明.txt」部署至 Vercel

🍎 macOS 13+

  1. 下載 builder-t{1,2,3}-v5.2.0.zip 至「下載項目」
  2. 雙擊 ZIP 自動解壓縮至同名資料夾
  3. 進入資料夾,找到 CHECKSUM.sha256
  4. 開啟「終端機」,執行 shasum -a 256 builder-t*.zip 對照
  5. 雙擊 setup.command 啟動設定精靈
  6. 若系統提示「無法驗證開發者」,右鍵 →「打開」→ 確認
  7. 依精靈指示填入:網站名、LOGO 路徑、電話、LINE ID、地址、主色碼
  8. 點擊「完成」,系統自動產出網站檔案至 output/
  9. 進入 output/,依「部署說明.txt」部署至 Vercel

❗ 安裝失敗常見原因

  • Node.js 未安裝或版本低於 v20 → 至 nodejs.org 下載 LTS 版
  • SHA-256 對不上 → 不要安裝,聯繫 客服 重發
  • setup 提示「權限不足」→ Windows 以系統管理員執行;macOS 在「系統設定 → 隱私權」允許

ℹ️ 客戶全程不需:寫程式、碰 Git、碰 Vercel 命令列、打終端機指令。setup 精靈會引導完成所有步驟。
