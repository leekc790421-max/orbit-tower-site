產品定位

T1 創業版是為「一個人也能開始」設計的單頁形象站懶人包。客戶不需寫程式、不需碰 Git,setup 精靈引導完成基本建置後,得到一個可對外展示的個人品牌門面。

適合對象

  • 接案者(設計師、文案、工程師)
  • 創作者(攝影、插畫、音樂)
  • 個人品牌(講師、顧問、部落客)
  • 剛起步、預算有限、需要快速上線者

交付內容

  • 單頁形象站模板(Hero + About + Works + Contact 四區塊)
  • README 安裝說明
  • setup 設定精靈(Windows / macOS)
  • SHA-256 驗證碼(CHECKSUM.sha256)
  • 保固卡(30 日保固)
  • 版本資訊
  • 部署指引(部署至 Vercel)

不包含項目

  • 多頁網站(請改選 T2 商務版或 T3 企業版)
  • 多語切換(繁中/英/日)
  • AI 接待員
  • 線上付款 / 金流串接
  • 會員系統 / 客戶後台
  • SEO 進階優化(僅含基礎 meta)
  • 客製設計(另行計價)

FAQ

T1 可以升級到 T2 或 T3 嗎?

可以。補差價即可升級,人工確認後重新組裝交付。

可以加購客製設計嗎?

可以。客製設計另行計價,先報價、書面確認後執行。

主機一年後怎麼辦?

一年後可續約主機(約 NT$500/年),或自行部署至其他平台。

需要我自己寫程式嗎?

不需要。setup 精靈引導完成所有步驟,客戶只需填寫網站名、LOGO、電話等資料。
