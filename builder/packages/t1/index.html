這包是做什麼的

給「一個人接案」的木工師傅與小工班。你的網站說清楚三件事：你做什麼工、做過哪些案子、業主怎麼找你。業主在 Google 搜你的工法與服務區域，看到你的作品，按 LINE 直接開口問價。不用你懂電腦，交付時全部架好。

適合對象

  • 個人木工師傅（天花板、櫃體、床組、系統櫃安裝）
  • 兩三人組成的小工班
  • 單項工種接案者（泥作、油漆、水电，也可用這包）
  • 案子靠口碑、想讓 Google 上也有人找到你的人

交付內容

  • 接案形象站一頁：服務項目＋服務區域＋關於師傅
  • 木工作品案例區（你給照片與說明，我們排版）
  • LINE 詢價按鈕（業主按了直接跳你的 LINE 對話）
  • AI 估價表單：坪數、需求、預算先收好，你看到的不是陌生來電
  • 基礎 SEO：工法關鍵字＋服務區域寫進標題與內文
  • 手機、平板、桌機全適（業主九成用手機看）
  • README 安裝說明＋Setup 設定精靈（Windows / macOS）
  • SHA-256 驗證碼（CHECKSUM.sha256）＋保固卡（30 日）＋部署指引

T1 常見問題

我完全不懂電腦，可以嗎？

可以。交付時網站已經架好、已經連上你的 LINE。你平常只做兩件事：完工拍照傳給我們排版、業主 LINE 進來要接。

T1 可以升級到 T2 或 T3 嗎？

可以。補差價即可升級，人工確認後重新組裝交付。

主機一年後怎麼辦？

續約約 NT$500／年，或自行搬走——交付含完整原始碼與部署說明，不綁約。

什麼時候會開始有詢價？

老實說：站上線只是起點，Google 收錄通常一到三個月起量。我們不保證天數，但每一步怎麼做都會講清楚。
