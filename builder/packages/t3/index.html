產品定位

T3 企業版是為「需要跨國曝光、多語溝通、AI 輔助接待」的 B2B 企業設計。多語多頁站含 AI 接待員腳本與 SEO/GEO 資產,讓海外客戶主動找到並理解你的產品。

適合對象

  • B2B 製造業(零組件、機械、代工)
  • 出口商(需要中英日多語展示)
  • 有海外客戶或想拓展海外市場者
  • 需要 AI 接待員輔助(客戶主動開啟時即時回應)
  • 需要 SEO/GEO 基礎建置者

交付內容

  • 多語多頁企業站模板(首頁 + 產品 + 工廠/關於 + 聯絡,共 4 頁 × 繁中/英/日)
  • AI 接待員腳本(客戶主動開啟時即時回應、整理需求,經 AI 附加條款)
  • SEO/GEO 資產(sitemap.xml、llms.txt、structured data JSON-LD)
  • 多語切換介面(繁中 / English / 日本語)
  • 產品展示區(圖文規格表)
  • README 安裝說明
  • setup 設定精靈(Windows / macOS)
  • SHA-256 驗證碼
  • 保固卡(30 日保固)
  • 版本資訊
  • 部署指引

不包含項目

  • 線上付款 / 金流串接
  • 會員系統 / 客戶後台
  • 訂單管理系統
  • CRM 客戶關係管理

  • 客製設計(另行計價)
  • 第三方服務費(網域、AI API、Vercel Pro 等)

FAQ

AI 接待員需要自己接 key 嗎?

是的。T3 交付 AI 接待員腳本,客戶需自行申請 Gemini / OpenAI API key 並填入。setup 精靈會引導。AI 接待標示:客戶主動開啟、系統被動回應、無背景監控。

可以加其他語言嗎(韓文、越文等)?

標準交付繁中/英/日三語。其他語言另行客製計價(每語 NT$3,000 起)。

SEO/GEO 資產包含什麼?

sitemap.xml、llms.txt、JSON-LD 結構化資料(Organization / Product / FAQPage)、IndexNow 推送設定。不含排名保證。

跨境付款怎麼處理?

海外客戶可走 Payoneer 跨境收款。台幣報價以匯率錨 1USD=32TWD 換算,實際以簽約報價單為準。

可以接 AGT-005 自動組裝嗎?

目前 T3 為人工組裝交付。AGT-005 自動串接為後續階段規劃,本版未含。
