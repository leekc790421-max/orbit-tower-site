產品定位

T2 商務版是為「有店面、有產品、需要多頁展示」的店家設計。多頁式網站含首頁、產品/菜單、品牌故事、聯絡資訊,客戶主動開啟詢問時能找到完整資訊。

適合對象

  • 餐飲業(咖啡廳、餐廳、小吃店)
  • 工作室(美甲、美髮、攝影工作室)
  • 實體店面(服飾、選物、烘焙)
  • 需要展示產品/菜單/價格的店家
  • 有品牌故事想傳達的小型商家

交付內容

  • 多頁店家站模板(首頁 + 產品/菜單 + 故事 + 聯絡,共 4 頁)
  • 產品/菜單展示區(圖文卡片式)
  • 品牌故事區
  • 聯絡資訊頁(含 LINE 連結、地圖嵌入)
  • README 安裝說明
  • setup 設定精靈(Windows / macOS)
  • SHA-256 驗證碼
  • 保固卡(30 日保固)
  • 版本資訊
  • 部署指引

不包含項目

  • 多語切換(繁中/英/日,請改選 T3)
  • AI 接待員(請改選 T3)
  • 線上付款 / 金流串接 / 購物車
  • 會員系統 / 客戶後台
  • 訂單管理系統
  • 客製設計(另行計價)

購買流程

  1. 客戶主動開啟 聯繫表單 或 LINE 詢問
  2. 人工確認需求(店家名、產品/菜單內容、品牌故事)
  3. 人工確認報價(NT$13,900,含一年主機)
  4. 客戶匯款(ATM / 銀行匯款,附驗證碼)
  5. 人工組裝 ZIP 並交付(含 README / setup / SHA-256)
  6. 客戶依 Setup Guide 安裝
  7. 驗收通過,保固起算(30 日)

FAQ

T2 可以放多少產品?

產品/菜單展示區為卡片式,標準 12 格。超過可加購擴充(每 12 格 NT$1,000)。

可以接線上點餐或購物車嗎?

T2 不含金流。如需線上點餐/購物車,請改選 T3 企業版或另行客製計價。

T2 可以升級到 T3 嗎?

可以。補差價即可升級,人工確認後重新組裝交付。

地圖怎麼嵌入?

setup 精靈會引導填入地址,自動嵌入 Google Maps。客戶不需處理技術細節。
