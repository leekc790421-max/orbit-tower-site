SHA-256 驗證說明

交付完整性驗證流程

為什麼要驗證

每個懶人包 ZIP 交付時,附帶一個 CHECKSUM.sha256 檔案。客戶下載後,需對照 ZIP 的 SHA-256 雜湊值——對不上就不准安裝,直接聯繫客服重發。

驗證步驟

  1. 下載 ZIP 與 CHECKSUM.sha256 至同一資料夾
  2. 打開 CHECKSUM.sha256,內容格式如下:
a3f5b8e2c1d4...  builder-t1-v5.2.0.zip
f7e9a1b3c2d5...  builder-t2-v5.2.0.zip
b2c8d4e6f1a3...  builder-t3-v5.2.0.zip
  1. Windows:PowerShell 執行 Get-FileHash builder-t*.zip -Algorithm SHA256
  2. macOS / Linux:終端機執行 shasum -a 256 builder-t*.zip
  3. 對照輸出的雜湊值與 CHECKSUM.sha256 內容
  4. 完全一致 → 可安裝
  5. 不一致 → 不要安裝,聯繫 客服 重發

❗ 對不上怎麼辦

雜湊值不一致代表 ZIP 在傳輸過程被竄改或損壞。不要安裝,立即聯繫客服重發。客服確認後會重新產生 ZIP 與新的 CHECKSUM.sha256。

ℹ️ 本版狀態:v5.2.0 為展示框架,尚未實際產生客戶 ZIP。SHA-256 驗證機制已就緒,實際交付時自動附帶 CHECKSUM.sha256。
