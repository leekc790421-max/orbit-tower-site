📋 懶人包內容

每個懶人包交付一個 ZIP 壓縮檔,解壓縮後包含:

  • README(本檔)— 安裝與使用說明
  • setup — 設定精靈執行檔
  • templates/ — 網站模板檔案
  • CHECKSUM.sha256 — SHA-256 驗證碼
  • warranty.txt — 保固卡
  • VERSION — 版本資訊

⚙️ 安裝流程

  1. 下載 ZIP 並解壓縮至本機任意目錄
  2. 開啟 CHECKSUM.sha256 對照 ZIP 雜湊值(詳見 SHA-256 驗證)
  3. 雙擊 setup 執行設定精靈
  4. 依精靈指示填入:網站名、LOGO、電話、LINE、地址、主色
  5. 點擊「完成」,系統自動產生網站檔案
  6. 將產出檔案部署至 Vercel(詳見 Setup Guide)

🚀 使用流程

  1. 客戶主動開啟 Builder,選擇 T1 / T2 / T3 方案
  2. 查看對應 Demo,確認是否符合需求
  3. 主動填寫需求表單(網站名、行業、預算區間)
  4. 人工確認需求與報價後,組裝交付 ZIP
  5. 客戶收到 ZIP,依本 README 安裝
  6. 安裝完成後,客戶主動測試;有問題聯繫客服
